# 🍲 Recipe Finder

Recipe Finder is a web application that generates random recipes each time you use it. This project is built using HTML, CSS, and JavaScript, and leverages an external API to fetch random recipes.

## ✨ Features

- 🎲 **Random Recipe Generation**: Get a new and unique recipe each time you use the app.
- 🌐 **API Integration**: Recipes are fetched from an external API to ensure a diverse selection.
- 🧑‍🍳 **User-Friendly Interface**: Simple and clean design for easy recipe browsing.
